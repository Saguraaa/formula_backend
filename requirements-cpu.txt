# ============================================================
# CPU 专用深度学习后端
#
# 适用：Cloud Studio 等平台的 CPU 规格工作空间、本地无 NVIDIA 显卡的机器。
#
# ============================================================
# 【重要】必须单独用 --index-url 安装，不要用 --extra-index-url
# ============================================================
#
# 原因：PyPI 上的 torch 默认就是 CUDA 版。若让 PyPI 与 CPU 索引同时可见
# （--extra-index-url），pip 会比较两边版本号并选中较高的一个，
# 结果又装回 CUDA 版，在无显卡机器上导入即报：
#   ImportError: libtorch_cuda.so: undefined symbol: ncclCommResume
#
# 正确安装顺序（先把 torch 钉死成 CPU 版，再装其余依赖）：
#
#   1) pip install --index-url https://download.pytorch.org/whl/cpu \
#          torch==2.14.0 torchvision==0.29.0
#   2) pip install -r requirements-base.txt -r requirements.txt
#   3) pip install paddlepaddle==3.0.0
#
# 顺序不可颠倒：若先装 requirements.txt，其中的 ultralytics 会把 CUDA 版
# torch 作为传递依赖拉进来（这不是猜测，PyPI 上的 torch 默认即为 CUDA 版），
# 之后再换 CPU 版就必须加 --force-reinstall 才盖得掉。
#
# ============================================================
# 以下行仅作版本记录；实际安装请按上面 1)~3) 执行。
# ============================================================

torch==2.14.0
torchvision==0.29.0

# PaddlePaddle CPU 版。本地开发环境用的是 GPU 开发版
# paddlepaddle-gpu==3.0.0.dev20250717，该版本不在 PyPI 上，
# 因此只能在 CPU / GPU 之间二选一，不能同时安装。
paddlepaddle==3.0.0
